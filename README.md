# FocusList Todo List

一个纯前端、零依赖的 Todo List 页面，可直接在浏览器中运行。

## 功能

- 新增、完成、取消完成、编辑和删除任务
- 可选截止日期，支持编辑/清除，并自动提示今天截止和已逾期任务
- 全部 / 待办 / 已完成筛选
- 全部、待完成、已完成任务统计
- 一键清除已完成任务
- 使用 `localStorage` 自动保存任务
- 浅色 / 深色主题，并记住主题偏好
- 响应式布局，支持桌面端和手机端
- 基础键盘操作和无障碍标签

## 运行

无需安装依赖。

直接打开 `index.html` 即可使用，也可以使用任意静态文件服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

任务数据仅保存在当前浏览器的本地存储中，不会上传到服务器。
